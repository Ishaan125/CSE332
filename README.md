# CSE332 Exercises

This workspace contains a set of standalone Java exercise folders for CSE332. Each directory is self-contained and usually includes a `Client.java` or `TestClient.java` entry point for quick manual testing.

## Repository Layout

- `Ex 0/` - stacks and queues
- `Ex 2/` - heaps and priority queues
- `Ex 4/` - binary search trees, AVL trees, and range trees
- `Ex 5/` - hash tables and word search
- `Ex 7/` - graph-based matching and donor graph code
- `Ex 9/` - clustering utilities and sample data sets
- `Ex 10/` - parallel algorithms and divide-and-conquer code
